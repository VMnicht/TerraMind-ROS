## 纯逻辑测试

在已完成构建的工作区根目录执行：

```bash
source /opt/ros/humble/setup.bash
source install/local_setup.bash
export ROS_LOG_DIR="$PWD/log/ros"
colcon test --event-handlers console_direct+
colcon test-result --verbose
```

`colcon test` 执行 CMake 登记的 GTest 和 pytest；下面的字节流/ROS/Qt 集成脚本还需单独运行。修改消息定义或 C++ 后先重新构建，避免测试旧产物。

- protocol_test：XMODEM 标准向量、文档全零帧、任意分块、噪声、坏 CRC、坏长度、未知和重复 TLV、非有限数值、控制/状态编码。
- transport_test：实际 PTY 读写、端口建议锁、无效设备及波特率。
- guard_test：禁用握手、连接代次、有效期与传输延迟预算、停机锁定、非法数值/时间戳。
- session_test：零指令确认、重复状态、过旧接纳序号、重启和帧序号回绕。
- discovery_test：字符设备别名去重、多帧识别、序号/运行时间回绕、候选无写入、多板歧义、重复帧失效、锁占用和取消。
- model_test：控制权接管、250 ms 超时、错误命令不续期、整帧拒绝、作业停止与差速运动。
- panel_controls：完整草稿、关闭归零、非法数值、底盘和作业能力限制。
- debug_launcher：子进程及孤儿进程组回收、参数引用、任务互斥、构建成功后启动、日志与退出。

## 独立字节流验证

`ros2 run terramind_sim serial_loopback_test.py` 使用 Python struct 和 binascii 独立生成/读取协议，不调用 C++ 编解码库，降低驱动和模拟器因共用错误编解码而互相验证通过的风险。它创建临时 PTY，验证分片、未知 TLV、序号回绕、CRC 错、越界值、不支持外设、重复 TLV、停止以及下位机超时。

ros2 service call /sim/drop_status std_srvs/srv/SetBool '{data: true}'
ros2 service call /sim/drop_status std_srvs/srv/SetBool '{data: false}'

```

## 现场联调待办

先核对接口电平、USART3 引脚、115200 8N1 和设备路径，再确认零快照接纳和实际能力。当前固件升降、喷洒初始化成功时为 0x003F，兼容 0x002F 和旧 0x000F。首次合法快照会接管 USART3，停机也不会退回 UART5。

逐项核对实际底盘前进和正角速度方向、左右播撒方向、刀盘油门设定、喷洒开关与 0～100% 目标，以及状态中的实际 RPM 含义。喷洒反馈需要同时核对目标、actual_percent 与 feedback_valid 的固件来源；没有有效反馈时不能将目标值视为实测值。填写真实轮径、轮距和必要减速比。逐项测量上层停止发布、串口拔出、板卡重启和 PC 退出后的响应；最后才对接后续自动任务。

软件测试不证明真实 USB 驱动、电气接口、电机执行和物理急停已验证。协议引用的固件源码及 tools/pc_protocol.py 不在本工程中，模型与真实固件的边界行为仍应交叉核验。

```

实际 ROS 进程联调已通过：二维后轴运动模型连接前置定位点生成器，经私有 PTY 驱动、200 ms 测量延迟和真实 `calibrate_lever_arm` 命令，完成正反各一圈。设定偏移为前方 0.80 m、左侧 0.12 m、高度 0.30 m、安装偏航 0.20 rad；识别的 X/Y 分别在 3 mm 容差内。即使驱动已有旧补偿，辨识仍使用原始测量点，不重复扣除。应用结果后的后轴位置误差小于 3 mm，Z 和安装旋转保持不变。所有机具关闭、完成后撤销使能、导航失效和 Ctrl+C 停机、失败不保存及恢复不续跑均已验证。
